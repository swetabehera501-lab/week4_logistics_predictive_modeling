# Week 4: Predictive Modeling and Optimization in Logistics Systems

## Files
- `logistics_prediction_dataset.csv`: 320 simulated shipments.
- `predict_logistics.py`: preprocessing, model comparison, cross-validation, hyperparameter tuning, evaluation, feature importance and chart.
- `requirements.txt`: Python dependencies.
- `outputs/`: sample metrics, predictions, feature importance, validation summary, and plots.
- `Week4_Logistics_Predictive_Modeling_Report.docx`: detailed report.

## Run on Windows / VS Code
1. Extract the ZIP, then use VS Code → File → Open Folder and select the extracted `week4_logistics_predictive_modeling` folder.
2. Open Terminal → New Terminal.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python predict_logistics.py`.
5. Review the files inside `outputs`.

The dataset is synthetic and educational. Use real historical data and time-based validation before operational use.
